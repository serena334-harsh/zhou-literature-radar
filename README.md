# 近题文献雷达 · RSP / RIO

公开访问：**https://serena334-harsh.github.io/zhou-literature-radar/**

面向广西民族大学周萍老师公开研究方向的个人文献辅助工作台，覆盖远程态制备与远程量子操作。本项目不是机构或课题组官方页面。

## 可以做什么

- 按方向、日期、证据类型、作者、DOI、协议属性与阅读状态筛选。
- 对照目标态 / 操作集合、纠缠资源、编码自由度、实现和控制条件。
- 保存个人在研档案、阅读笔记、排除理由和行动清单；导出 JSON、BibTeX 与 Markdown。
- 每日洛杉矶时间 09:00 通过 GitHub Actions 检查 arXiv 和 Crossref 的公开元数据，留存来源与失败项。任务实际执行时间可能延后。

## 公开资料与个人数据

`public/data/public-radar.json` 只包含公开文献、公开方向和检查报告。个人编辑、稿件摘要与笔记只保存在当前浏览器；不会上传到 GitHub，也不会分享给其他访问者。更换浏览器前请使用完整备份。

初始 12 篇资料为人工核验的摘要和元数据基线。后续自动收录明确标记为**元数据候选**，需人工核验原始摘要与全文。自动标签不构成稿件重叠、抄袭或创新性结论。预印本、期刊版本、首次发表、卷期日期与首次发现分开记录。全文与 PDF 请通过原始链接访问。

## 本地运行

```sh
npm ci
npm run dev
npm test
npm run build
```

公开网页由 `main` 分支的 GitHub Actions 构建部署。定时扫描仅使用脚本中的公开检索词；不读取访问者浏览器中的档案。没有任何额外 API 密钥要求。
